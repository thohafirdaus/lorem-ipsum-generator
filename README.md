# Lorem Ipsum Generator

A clean and efficient tool to generate random Lorem Ipsum text by words, sentences, or paragraphs.

## Features

- **Three Generation Modes:** Choose between words, sentences, or paragraphs.
- **Quantity Control:** Input the desired amount (up to 500 units).
- **Copy to Clipboard:** One-click feature to copy generated text with visual feedback.
- **Responsive Design:** Optimized for both mobile and desktop devices.
- **Smooth Animations:** Powered by `motion` for a better user experience.

## Tech Stack

- **React & TypeScript:** For robust application logic.
- **Tailwind CSS:** For modern and responsive styling.
- **Lucide React:** For clean iconography.
- **Motion:** For interactive user experience.
